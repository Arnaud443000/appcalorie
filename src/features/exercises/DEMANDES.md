# Demandes du lot « Écrans d'exercices »

Aucune demande bloquante. Deux suggestions pour le lot 0 (facultatives) :

1. `Screen` : un titre long (« Développé couché barre ») est coupé par « … » sur 390 px.
   Un retour à la ligne (ou une taille un peu plus petite) serait plus lisible.
2. `Chip` n'a pas de variante de couleur : les muscles principaux (rouge) et secondaires (rose)
   sont colorés ici par un habillage CSS du lot. Une prop `tone` dans `@/ui` serait plus propre.
